1. DaMoA v3.8 시스템 개요

DaMoA(다모아)는 크리에이터, 인터넷 방송인, 버추얼 유튜버의 다양한 소식을 디스코드 서버로 신속하고 아름답게 전송하는 고성능 멀티플랫폼 알림 엔진입니다.

⚡ 초고속 실시간 감지 파이프라인

유튜브, 치지직, SOOP, 씨미의 방송 상태를 30~35초 간격으로 밀착 감지하여 방송 시작 1분 내에 지연 없이 즉각 전달합니다.

🎨 공식 Discord Components v2 레이아웃

구형 Embed를 완전히 탈피하여 네이티브 아바타 액세서리, 섹션 분할기, 반응형 미디어 갤러리 및 링크 버튼을 제공합니다.

🛡️ 100% 무손실 전달 & 자가 치유

Discord 429 Rate Limit 지수 백오프 재시도 및 채널 웹훅 무단 삭제 시 1초 만에 자동 재생성하는 자가 치유(Self-Healing) 엔진 탑재.

2. 봇 초대 및 필수 디스코드 권한 체크리스트

DaMoA 봇이 디스코드 채널에 고품질 웹훅 메시지를 정상 전송하기 위해 다음 권한이 반드시 필요합니다:

권한 명칭 권한 비트 / 용도 필수 여부
웹훅 관리 (Manage Webhooks) 크리에이터의 프로필과 아바타로 실시간 전송하기 위한 필수 권한 절대 필수
메시지 전송 (Send Messages) 웹훅 미사용 또는 비상 폴백 시 봇 계정으로 직접 메시지 발송 절대 필수
링크 삽입 (Embed Links) 방송 썸네일, 다시보기 링크, 배너를 풍부하게 표시하기 위한 권한 절대 필수
역할/모두 멘션 (@everyone, @here, Role Mention) 새 방송 또는 새 게시물 등록 시 팬/구독자 역할 멘션 알림 울림 권장
메시지 기록 보기 (Read Message History) 이전 알림 자동 언핀(Unpin) 및 신규 핀(Pin) 고정 관리 기능 권장
💡 가장 간편한 방법: 봇 초대 시 Administrator(관리자) 권한을 부여하시면 채널별 권한 설정 누락으로 인한 전송 실패를 100% 예방할 수 있습니다.

3. 플랫폼당 30개 독립 슬롯 (서버당 총 240개 슬롯) 시스템

많은 봇들이 모든 플랫폼을 통틀어 5개~10개의 알림만 제공하는 반면, DaMoA는 8개 플랫폼 각각에 30개씩 독립된 슬롯(총 240개)을 무료로 제공합니다.

각 플랫폼은 슬롯 #1 ~ #30까지 완전히 독립된 저장 공간과 채널/역할/맞춤 메시지를 가집니다.

유튜브 (YouTube) 30개 슬롯 (#1 ~ #30) 새 영상, 쇼츠, 커뮤니티 글, 라이브 방송, 프리미어
치지직 (CHZZK) 30개 슬롯 (#1 ~ #30) 라이브 시작, 방송 종료, 예약 방송, 드롭스 태그

5. 알림 이벤트 종류 & 트리거 조건

방송 종료(Live End) 오알림 차단 메커니즘

기존 봇들에서 가장 빈번하게 발생하는 "방송을 켠 적도 없는데 방종 알림이 오는 버그"는 DaMoA v3.8에서 완전히 해결되었습니다.

🛡️ 상태 잠금(State Guard) 검증 파이프라인
DaMoA는 DB의 live_state 캐시에서 실제로 live: true(방송 진행 중) 상태를 거친 채널에 대해서만 방송 종료 이벤트를 발생시킵니다. 방송을 하지 않는 평상시의 오프라인 상태나 일일 ID 변경 시에는 절대 방종 알림이 발생하지 않습니다.

방송 종료 알림 시 영상 배너 및 상세 설명 보존

방송이 끝난 후에도 방송 당시의 제목, 게임 카테고리, 방송 썸네일 배너가 온전히 보존되어 전송됩니다. 또한 바로가기 버튼을 누르면 채널 홈이 아닌 해당 방송의 다시보기(VOD) 및 스트림 플레이어로 즉시 이동합니다.

6. Discord Components v2 최신 규격 렌더링

DaMoA는 Discord API 공식 Components v2 (플래그 1 << 15)를 지원합니다:

  • Section & Accessory: 우측 상단에 크리에이터의 원형 프로필 이미지를 깔끔하게 렌더링 (플랫폼 로고가 아닌 방송인 본인의 사진).
  • 상세 본문 (Detailed Text): 유튜브 설명글 타임라인(챕터 01:23)을 감지하여 클릭 시 해당 시간대로 바로 이동하는 하이퍼링크 자동 변환.
  • 미디어 갤러리: 인스타그램 캐러셀 다중 사진(최대 10장)을 디스코드 격자 갤러리로 동시 표시.
  • 인터랙티브 액션 버튼 (최대 5개): '원문 보기' 외에 '팬카페 바로가기', '후원 링크', '다시보기' 등 커스텀 링크 버튼 지원.
  • 하단 푸터 & 시각 동기화: 플랫폼 서버와 디스코드 타임스탬프 간 1초 단위 시간 오차를 보정하여 정확한 KST 시각 표기.

7. Discord 봇 명령어 총정리

/시작하기

서버 관리자 전용 대시보드를 인터랙티브 메시지로 호출합니다. 인스타그램, 트위터, 스포티파이, 씨미, 치지직, 유튜브, 네이버 카페, SOOP 각각의 알림 대상 수(N / 30)를 확인하고 [알림 추가], [알림 관리] 버튼으로 즉시 세팅할 수 있습니다.

/테스트알림 [platform]

지정한 플랫폼의 실시간 알림 페이로드를 현재 채널(또는 설정된 알림 채널)로 즉시 전송하여 웹훅 상태와 레이아웃을 점검합니다.

/설정확인

현재 서버에 등록된 8개 플랫폼의 활성화된 슬롯 목록과 전송 채널, 역할 멘션 상태를 종합 요약하여 보여줍니다.

8. 웹 대시보드 (Web App) & 위지윅 에디터 사용 가이드

웹 대시보드(damoa.teamlight.pe.kr)는 마우스 클릭 몇 번으로 서버의 모든 알림을 제어할 수 있는 프리미엄 공간입니다:

🖥️ 실시간 위지윅(WYSIWYG) 미리보기

모달 창에서 URL, 맞춤 메시지, 역할을 변경할 때마다 우측의 Discord Components v2 화면이 실시간으로 변동되어 실제 전송 모양을 미리 확인할 수 있습니다.

🔗 지능형 URL 자동 감지 라우터

URL 입력란에 링크를 붙여넣는 즉시 정규식으로 유튜브, 치지직, SOOP 등을 감지하여 플랫폼 선택기를 자동으로 전환하고 다음 빈 슬롯을 자동 배정합니다.

📊 구독자/시청자 변동 추세선

크리에이터의 구독자 성장 곡선과 방송 회차별 최고 동시 시청자 수(Peak Viewers) 타임라인을 스파크라인 그래프로 모니터링합니다.

9. 백엔드 무손실 자가 치유(Self-Healing) 엔진

DaMoA 백엔드는 상시 무중단 운영을 위한 4중 안전망을 갖추고 있습니다:

  1. 지수 백오프(Exponential Backoff) 파이프라인: Discord API 429(속도 제한) 발생 시 1초, 2초, 4초 대기 후 100% 무손실 재전송.
  2. 웹훅 자가 치유(Auto-Healing) 엔진: 관리자나 다른 봇이 채널 웹훅을 실수로 삭제(HTTP 404)해도 1초 만에 감지하고 즉시 재생성 후 DB 자동 갱신.
  3. Neon DB 연결 풀 고갈 방지 매니저: TCP Keepalives와 자동 재연결로 서버리스 유휴 연결 끊김을 완벽 방어.
  4. Vercel Serverless 무중단 웜업 핑: 4분 간격 크론 핑으로 콜드 스타트로 인한 첫 알림 딜레이 차단.

10. 자주 묻는 질문 & 트러블슈팅 20선

Q1. 알림이 5분 이상 늦게 오는 현상은 왜 발생하나요?

이전 버전에서 유튜브 기본 폴링 간격이 300초(5분)로 설정되어 있었으나, 최신 패치를 통해 35초 초고속 폴링으로 개선되었습니다. 이제 영상 공개 즉시 1분 이내에 알림이 수신됩니다.

Q2. 방송을 한 적도 없는데 '방송 종료' 알림이 오던 버그는 어떻게 고쳐졌나요?

방송 진행 여부(live: true)를 검증하지 않고 오프라인 상태에서 방종 이벤트를 쏘던 공급자 로직을 수정하여, 실제 방송을 진행한 이력이 있는 경우에만 방종 알림이 발생하도록 안전장치를 적용했습니다.

Q3. 방송 종료 알림의 버튼을 누르면 채널 홈으로 가던 문제는 해결되었나요?

네! 방송 종료 알림의 바로가기 링크는 프로필 메인이 아닌 해당 방송의 다시보기(VOD) 및 스트림 플레이어 직링크로 자동 연결됩니다.

Q4. 웹앱에서는 왜 플랫폼 통틀어 30개만 설정되었었나요?

웹 UI에서 전체 슬롯 카운트를 합산 표시하던 오류를 완전히 수정하여, 디스코드 /시작하기와 동일하게 각 플랫폼별 30개씩 (총 240개) 독립적으로 세팅할 수 있도록 개편했습니다.

Q5. 테스트 알림 버튼을 누르면 왜 404나 전송 실패가 떴었나요?

봇 명령어의 변수 참조 순서 오류 및 웹 대시보드 버튼의 이벤트 리스너 누락을 모두 수정하였으며, 채널에 웹훅이 없어도 봇이 자동 생성 후 전송하도록 강화되었습니다.

Q6. 서버 웹훅을 실수로 삭제하면 어떻게 되나요?

DaMoA의 웹훅 자가 치유(Auto-Healing) 엔진이 404 응답을 즉각 포착하여 1초 만에 웹훅을 다시 생성하고 DB를 갱신하므로 알림이 끊기지 않습니다.

Q7. 트위터의 긴 글(280자 초과 X 프리미엄)도 안 잘리고 오나요?

네, 트위터 긴 글 전문 수집 파이프라인을 통해 최대 15,000자까지 본문 잘림 없이 온전하게 전송됩니다.

Q8. 인스타그램 사진이 여러 장일 때 모두 볼 수 있나요?

인스타그램 캐러셀 기능을 통해 최대 10장의 사진이 디스코드 미디어 갤러리로 깔끔하게 렌더링됩니다.

Q9. 유튜브 타임스탬프 링크는 어떻게 작동하나요?

영상 설명에 적힌 01:23 하이라이트 같은 시간대를 자동 인식하여 클릭 시 해당 초로 바로 점프하는 하이퍼링크로 변환됩니다.

Q10. 게임 카테고리 이름이 한글로 번역되나요?
