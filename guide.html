GETTING STARTED

DaMoA 시작 가이드

봇 초대부터 첫 알림 설정까지, 5분이면 충분해요.

1

DaMoA 봇을 서버에 초대하세요

아래 버튼을 눌러 DaMoA 봇을 내 Discord 서버에 초대합니다.
봇이 알림을 전송하려면 메시지 전송, 링크 삽입, 웹훅 관리 권한이 필요합니다.

봇 초대하기 →
2

Discord에서 /시작하기 명령어를 실행하세요

서버에 봇이 추가된 후, 알림 설정을 원하는 채널에서 슬래시 명령어를 입력합니다.

/시작하기

⚠️ 이 명령어는 서버 관리자 권한이 있는 멤버만 사용할 수 있습니다.

3

플랫폼과 채널 링크를 선택하세요

봇이 추적할 스트리머 또는 채널의 공개 프로필 URL을 입력하고, 알림을 받을 Discord 채널과 멘션할 역할을 선택합니다.

치지직: https://chzzk.naver.com/{채널ID}
SOOP: https://ch.sooplive.co.kr/{채널명}
YouTube: https://youtube.com/@{채널명}
X(트위터): https://x.com/{계정명}
Instagram: https://instagram.com/{계정명}
Spotify: https://open.spotify.com/artist/{ID}
네이버 카페: https://cafe.naver.com/{카페명}
4

알림 종류를 선택하세요

받고 싶은 이벤트 유형을 체크합니다. 플랫폼에 따라 선택 가능한 이벤트가 달라집니다.

예를 들어 치지직/SOOP은 라이브 시작, 방송 종료, 방송 예약을 선택할 수 있고, YouTube는 새 영상, 쇼츠, 커뮤니티 글, 프리미어까지 지원합니다.

5

웹 대시보드에서도 관리할 수 있어요

damoa.teamlight.pe.kr에 접속해 Discord 로그인 후, 관리 중인 서버를 선택하면 웹에서 슬롯 추가·수정·삭제가 가능합니다.

테스트 알림 전송 기능으로 설정이 올바른지 바로 확인할 수 있어요.

자주 묻는 질문

봇 초대 후 /시작하기 명령어가 안 보여요

봇 초대 후 1~2분 지나면 자동 등록됩니다. Discord 앱 재시작 또는 서버 설정 → 통합(Integrations)에서 확인해주세요.

알림이 오지 않아요

1. 알림이 켜짐 상태인지 확인 · 2. 봇에 메시지 전송/링크 삽입 권한이 있는지 확인 · 3. 등록한 URL 형식이 올바른지 확인 · 4. 치지직/SOOP은 실시간, YouTube/SNS는 1~3분 폴링입니다.

서버당 몇 개까지 등록할 수 있나요?

서버당 최대 30개의 알림 슬롯을 완전 무료로 제공합니다.

관리자가 아닌 멤버도 설정할 수 있나요?

아니요. 알림 설정은 서버 관리자 권한(Administrator)을 가진 멤버만 사용할 수 있습니다.

DaMoA는 무료인가요?

현재 모든 기능이 완전 무료로 제공됩니다.
